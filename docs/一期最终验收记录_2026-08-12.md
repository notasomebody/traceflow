## 需要用户环境验证

以下功能的代码、边界和错误处理已测试，但项目没有保存或使用用户的付费凭据，因此无法在自动化验收中发起真实调用：

- OpenAI API：需要用户自己的有效 API Key。
- OpenAI 兼容接口：需要用户实际服务地址、模型名和 API Key。
- Ollama：需要用户本机安装并下载模型。
- Codex 本地引擎：需要本机 Codex CLI 和用户自己的 API Key。
- Windows 凭据管理器保存 Key、开机启动注册项：需要用户在安装版界面手工确认系统提示和实际登录行为。

这些项目在没有对应环境时会给出明确错误，不影响本地采集、项目归类、日报周报月报、离线配置分享和加密备份。
