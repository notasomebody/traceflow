# 迹汇 TraceFlow 用户手册：零整理自动接管版

## 直接交给 Codex 的指令

把本页链接交给 Codex，并发送下面这段话：

```text
请按照 https://github.com/notasomebody/traceflow/blob/main/docs/迹汇用户手册_零整理自动接管版.md 帮我安装并初始化迹汇。
只从最新稳定版 Release 下载并校验安装包，不克隆源码，不使用预发布版。
能安全自动完成的步骤直接完成，不要让我回答简单问题。
只在 Windows 安全确认、外部系统登录、正文读取授权和外部写入前让我操作。
默认只读，不要替我提交企业微信汇报、填写 Jira 工时或修改外部系统。
```

## Codex 执行边界

- 只从 https://github.com/notasomebody/traceflow/releases/latest 下载正式安装包、安装脚本和 SHA256SUMS.txt。
- 下载后先校验 SHA-256，再安装和启动。校验失败立即停止。
- 不克隆源码，不使用 Actions 临时产物、第三方镜像或草稿版。
- 不要求用户在对话中发送密码、Cookie、Secret 或 API Key。
- 企业微信 UI Automation 只允许读取汇报列表、汇报正文和返回列表。
- 禁止点击编辑、删除、提交、发送、撤回、审批、新建或保存。
- 用户开始操作电脑时，历史读取必须暂停；空闲后从进度继续。
- 截图和本地 OCR 默认关闭，只有用户明确授权后才能作为 UI Automation 读取失败时的兜底。
- 迹汇生成的日报在用户最终检查前不能提交到外部系统。

## 一条龙安装

1. 检查默认安装位置 `%LOCALAPPDATA%\TraceFlow\迹汇 TraceFlow.exe`。
2. 未安装时下载最新稳定版中的 `install-latest.ps1` 与 `SHA256SUMS.txt`。
3. 校验脚本摘要，确认脚本只访问 GitHub、安装迹汇并检查本机接口。
4. 从本地文件执行脚本。Windows 出现未知发布者提示时交给用户本人判断。
5. 启动后检查 `http://127.0.0.1:17890/actuator/health` 返回 `UP`。
6. 打开迹汇，完成一个页面的首次引导。

## 用户第一次只需做什么

首次引导只保留三项必要内容：

1. 确认每日默认工时，默认 8 小时。
2. 决定是否允许读取今天实际修改的工作文件正文。不开启时只读取文件名和修改时间。
3. 点击“开始自动整理”。

点击后迹汇会自动开启前台工作采集、工作文件发现、项目归类、企业微信被动学习和空闲补读策略。截图与 OCR 不会随之开启。

## 自动整理如何工作

迹汇只检查文档、桌面及 OneDrive 中今天实际修改的常用文本类工作文件，不扫描整块硬盘。它自动排除：

- `.git`、`node_modules`、`target`、`dist`、`build` 等仓库和构建目录；
- `.env`、凭据、私钥、证书、密码库等敏感文件；
- 超过安全大小限制的文件和不支持的二进制文件。

同一个文件没有变化时不会重复导入；再次修改后才形成新证据。授权正文后，文件中的实际成果说明会进入日报，而不只是文件名。

含相同 Jira 问题前缀的可靠记录重复出现三次后，迹汇会自动建立对应项目并归类。无法可靠判断的内容按“其他工作”或工作主题汇总，不要求用户逐条确认。

## 自动读取企业微信历史汇报

普通用户不需要管理员 API：

1. 在迹汇打开“汇报中心”并选择“从企业微信导入”。
2. 首次使用时在设置中授权 UI Automation 文本读取。
3. 打开企业微信汇报列表。
4. 回到迹汇点击“自动补齐最近 90 天汇报”，并在 3 秒内切回企业微信。
5. 之后正常工作即可。检测到鼠标或键盘活动时迹汇会暂停，电脑空闲后继续。

迹汇保存已访问和已导入进度，重启后不会重复导入相同汇报。日期、今日工作总结和下一步计划会拆分后加密保存到本机。

不同企业微信版本的控件结构可能不同。如果找不到安全的返回按钮，迹汇会停止并提示，不会模拟未知点击或键盘操作。真实公司客户端首次使用仍需观察一次结果。

企业管理员也可以在高级连接中配置 CorpID 与“汇报”应用 Secret，通过官方 API 批量读取。普通用户的本机登录状态不能替代管理员授权。

## 每天的使用方式

- 正常使用 Codex、IDE、Word、PPT、浏览器和业务系统，不需要逐项记录。
- 迹汇在后台整理窗口活动和今天修改的工作文件。
- 17:50 自动形成日报与工时草稿。
- 用户只检查一次项目、事实和敏感信息，必要时修改。
- 18:00 后由用户确认，再复制到企业微信提交。

周报和月报从已保存日报汇总，不要求重复填写。PPT 素材可以交给 Codex 或其他工具，并由用户选择模板生成。

## 数据安全

- 本地服务只监听 `127.0.0.1`。
- 工作记录、识别正文和日报在本机数据库中加密保存。
- API Key 和企业微信 Secret 使用系统凭据存储，不写入配置分享码。
- 配置分享码排除姓名、密码、令牌、报告和历史正文。
- “清除本机私有数据”会关闭监控与自动整理，停止企业微信读取，并删除截图、自动整理游标、企业微信去重记录和安全凭据。
- 外部 AI 调用前必须展示将发送的文本并由用户确认。

## 验收清单

Codex 完成初始化后只需汇报以下结果：

- 安装包 SHA-256 是否一致；
- 迹汇是否启动；
- 本机健康接口是否为 `UP`；
- 自动采集是否已按用户选择开启；
- 文件正文读取是否符合用户授权；
- 企业微信 UI Automation 是否已授权；
- 历史读取当前状态、已查看条数与已导入篇数；
- 当前仍需用户处理的真实限制。

不得把“程序已启动”当作“企业微信真实环境已完全兼容”。只有在受控测试通过并由用户在实际客户端观察一次后，才能确认该项可用。
