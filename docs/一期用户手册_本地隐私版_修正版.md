# 迹汇 TraceFlow 一期用户手册

## 安装与首次启动

1. 从本项目发布页下载安装包，双击安装。当前安装包未做商业代码签名，Windows 可能提示“未知发布者”。
2. 首次启动按引导设置每日目标工时、日报生成时间和 AI 使用方式。
3. 活动监控、截图和 OCR 默认关闭。只有用户主动开启后才运行。
4. 关闭主窗口后程序缩小到托盘；从托盘可打开、开始采集、暂停 15 分钟、暂停 1 小时、暂停到明天或彻底退出。

## 日常使用

- 先在“项目库与待归类”创建当前项目，并填写应用名、项目简称等识别关键词。
- 高置信度活动自动归类；无法判断的记录进入待归类列表，由用户集中确认。
- 相同应用和窗口在 10 分钟内自动合并。今日活动可人工修正时长或删除。
- 会议、培训可从工作时间线顶部直接记录为“公共事务”。
- 默认工作日 17:50 自动生成日报草稿；错过时间后当天首次启动会补生成。休息日不生成，调休补班日按工作日处理。
- 日报必须由用户检查和确认。周报、月报从已保存日报汇总，可复制到企业微信等系统。
- 左侧“历史记录”支持导入旧日报；同日期再次导入会保存新版本快照，报告正文加密落库。
- 左侧“企业微信”支持粘贴历史汇报，或在授权 UI Automation 后读取当前打开的企业微信汇报窗口。读取结果必须检查后再导入。
- 左侧导航是独立页面切换，从“设置”“历史记录”或“企业微信”均可直接返回“今日工作”。

## UI Automation 与截图 OCR

- 本地内容识别默认关闭。用户可先单独授权 UI Automation 文本读取；它不截图，并跳过密码控件。
- UI Automation 能读取有效内容时不会调用 OCR。只有 UIA 无有效内容且用户另行授权“OCR 兜底”后，才截取当前活动窗口，不截取整个桌面。
- 企业微信读取严格限制为当前活动的 `WXWork.exe` / `WeCom.exe` 窗口，不后台遍历历史记录，也不自动提交。
- 采集频率可在 1～30 分钟调整。
- 原图默认立即删除；如选择保留 1、3 或 7 天，文件会使用 Windows DPAPI 加密。
- OCR 文本和报告正文写入数据库前使用 AES-256-GCM 加密。
- 截图和 OCR 不会自动发送给外部 AI，发送前必须预览并确认。

## AI 与 Codex

- 支持 OpenAI、OpenAI 兼容接口、本机 Ollama 和 Codex 本地引擎。
- API Key 保存到 Windows 凭据管理器，前端无法读回明文。
- OpenAI 固定使用官方 Responses 地址；Ollama 仅允许连接本机回环地址。
- 外部 HTTP 请求 90 秒超时、响应上限 2 MB；Codex 超过 180 秒会终止。
- 没有 API Key 也能使用本地草稿、复制和离线配置分享功能。

## 备份、迁移与隐私

- 设置页可导出 `.tfbackup` 加密备份，并在另一台电脑恢复。
- 备份使用 PBKDF2-HMAC-SHA256 和 AES-256-GCM，不依赖原电脑。密码不会保存，也无法找回。
- 备份包含项目、活动、OCR、日报、周报、月报和历史快照；不包含 API Key、系统凭据和截图原图。
- 配置分享码与数据备份不同：分享码只分享设置，自动排除姓名、密钥、报告和历史记录。
- “彻底清除本机数据”需要二次确认，并删除数据库隐私数据、截图缓存、日志和 AI Key。
- 所有本地接口仅监听 `127.0.0.1`，不提供中心服务器。

## 当前一期边界

- 已实现：Windows 本地采集、项目归类、截图 OCR、日报周报月报、AI/Codex、加密备份、托盘和开机启动。
- 企业微信当前窗口读取和历史日报导入已实现；Jira 工时自动填写、企业微信自动提交和浏览器自动化属于二期。
- PPT 模板生成和 macOS 正式版属于三期。
- 外部模型真实连通性需要用户自己的有效 API Key；项目测试不会代替用户调用付费接口。
