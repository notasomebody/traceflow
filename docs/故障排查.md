# 故障排查

## 程序启动后一直显示“本地服务正在启动”

首次启动 Java 后端可能需要数秒。等待 15 秒后点击“立即同步”。如果仍失败：

1. 确认没有安全软件阻止迹汇启动本地进程。
2. 检查 `17890` 端口是否被其他程序占用。
3. 在设置中生成脱敏诊断包，不要直接发送整个数据库。

## Windows 显示“未知发布者”

第一版安装包尚未进行商业代码签名。请确认文件来自本仓库 GitHub Releases，并核对发布页中的 SHA-256。不要运行来自网盘或聊天群的重新打包版本。

## 关闭窗口后程序仍在运行

为保证 17:50 自动生成，点击关闭会默认缩小到系统托盘。右键托盘中的小鱿图标并选择“彻底退出”，才会停止本地后端和定时任务。

## 锁屏或企业微信没有打开

桌面自动化需要可交互的桌面会话。锁屏、企业微信未启动或界面发生变化时，迹汇应停止自动操作并保留待提交任务。解锁并打开企业微信后，可手动重试。

## 数据源登录失效

迹汇不会绕过验证码、统一认证或平台安全策略。请在数据源设置中重新登录。不要把 Cookie、密码或浏览器会话导出到分享码。

## 分享码无法导入

- 确认分享码从 `TF1.` 或 `TF1E.` 开始并复制完整。
- `TF1E` 是加密分享码，需要正确的分享密码。
- 校验失败说明内容不完整或被修改，应让发送者重新生成。

## 如何反馈问题

普通问题请提交 GitHub Issue。发送日志或截图前，删除账号、内网地址、项目名和真实工作内容。安全问题请按照 `SECURITY.md` 私下报告。
