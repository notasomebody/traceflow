# 迹汇 TraceFlow 一期至三期迭代规划（监控与 AI 版）

更新日期：2026-08-11

## 产品目标

迹汇是一款本地优先的 Windows 工作记录助手。它在用户明确授权的工作时段内采集必要的本机活动元数据，把工作痕迹归入用户创建的项目，并生成可编辑、可追溯的日报、周报和月报。

产品不记录具体键盘输入或鼠标内容，不在后台静默上传截图、窗口标题、OCR 文字和报表正文。任何外部模型或 Codex 调用都必须经过用户预览和确认。

## 一期冻结范围

一期不拆分里程碑。以下功能全部实现并通过验收后，才能发布一期正式版。

### Windows 桌面与运行

- 支持 Windows 10 和 Windows 11。
- 提供可点击安装的 EXE 安装包。
- 支持关闭窗口后驻留托盘、托盘重新打开和彻底退出。
- 首次引导中征求开机自启动授权。
- 小鱿托盘图标放大并根据状态变色：绿色采集、紫色 OCR、黄色暂停、红色异常、灰色关闭。
- 锁屏、待机、非工作时间和连续空闲时暂停采集。

### 工作时间与性能

- 使用可拖拽多区间时间轴配置工作时间，按 15 分钟吸附，同时支持精确输入。
- 默认工作日 09:00–12:00、13:30–18:00，可复制到其他工作日。
- 支持中国法定节假日、特殊加班日和临时继续采集。
- 默认连续 5 分钟无操作判定为空闲，允许调整为 1–30 分钟。
- 同项目、同应用活动默认按 10 分钟间隔合并，允许调整、拆分和重新归类。
- 电池供电、高 CPU 占用和 OCR 队列拥堵时自动降级或暂停截图识别。
- 安装包目标不超过 100 MB，常驻内存目标不超过 200 MB，仅元数据监控时平均 CPU 目标低于 1%。

### 项目与归类

- 用户维护正式项目，包含名称、简称、状态和识别规则。
- 内置公共事项分类，用于会议、培训和日常支持。
- 无法判断的记录进入待归类。
- 高置信度记录自动归类，低置信度记录集中确认。
- 项目创建可跳过；未配置项目时不使用虚构示例项目。
- 用户修正结果形成仅保存在本机的识别规则。

### Windows 活动采集

- 采集当前前台应用名称、窗口标题、活跃时间段和系统空闲时长。
- 浏览器一期只使用网页标题，不读取完整网址和浏览历史。
- 不采集具体键盘输入、鼠标操作内容和剪贴板。
- 默认排除密码管理器、银行支付、系统凭据和远程登录等敏感窗口。
- 用户可配置应用排除规则，并可从托盘暂停 15 分钟、1 小时或到次日。

### 截图识别与本地 OCR

- 截图识别默认关闭，开启时必须明确授权。
- 只截取当前活跃窗口，不截整个桌面和其他显示器。
- 切换窗口时触发；同一窗口默认最多每 5 分钟一次，允许调整为 1–30 分钟。
- 优先使用 Windows 系统 OCR；高精度离线模型不进入主安装包。
- 原始截图默认处理完成后立即删除。
- 用户可选择将原图加密保留 1、3 或 7 天。
- OCR 只保留项目归类和总结所需结果，支持预览、删除和清空。
- 截图永不自动上传；发送到外部模型前必须逐次预览并确认。

### 报表

- 日报按当天已确认工作事件生成。
- 周报汇总本周已确认日报，按项目去重和归纳。
- 月报汇总当月已确认日报和周报，按项目展示进展、时间和待办。
- 默认 17:50 生成日报；周五 17:50 生成周报；当月最后一个工作日 17:50 生成月报。
- 遇节假日提前到最近工作日；错过时间后在下次启动或解锁时补生成本地草稿。
- 支持编辑、补充、删除、项目调整、复制和重新生成。
- 每次重新生成或 AI 润色保留版本历史；确认后生成只读快照。
- 不编造工作成果、数字、进度和工时。

### AI 与 Codex

- 本地规则模式无需模型即可生成基础报表。
- 支持 OpenAI 官方 API、OpenAI-compatible API 和本机 Ollama。
- 支持配置 API 地址、API Key、模型、超时和最大输出长度。
- 支持复用本机 Codex 登录或使用 OpenAI API Key连接 Codex SDK。
- API Key默认保存到 Windows 凭据管理器，也可仅本次使用。
- 连接测试只发送固定测试文本，不发送真实工作数据。
- 每次实际调用都展示发送内容、目标服务和模型，用户确认后才发送。
- 失败时保留本地草稿，不重复静默调用，不自动切换到其他模型。

### 数据安全

- 本地接口只监听 127.0.0.1。
- 窗口标题、OCR 文本和报表正文等敏感字段加密存储。
- 数据密钥通过 Windows DPAPI绑定当前 Windows 用户。
- API Key和令牌不进入 SQLite、日志、统计、配置导出和分享码。
- 配置分享码不包含姓名、凭据、工作记录和历史报表。
- 历史数据只能导出为密码加密备份包。
- 日志不得记录截图、窗口标题、OCR 正文、报表正文或凭据。
- 用户可查看存储占用、保留期限并彻底清空数据。

### 质量与交付

- 每个可操作功能必须有自动化测试或可重复人工验收步骤。
- 测试报告必须区分通过、部分可用、未实现和失败。
- 不可用功能必须在界面和 README 中明确标注，不能用可点击空入口代替。
- 一期正式发布前执行安装、升级、卸载、锁屏、休眠、离线、断网、低电量和异常退出测试。

## 二期规划

- Jira 自动创建问题、指派本人、公共任务映射和 ActivityTimeline 工时填报。
- 企业微信客户端日报、周报自动填写，确认后在允许时间提交。
- 浏览器扩展，按用户授权读取域名和页面类型，提高项目识别率。
- 高精度 OCR 可选下载包及模型管理。
- 更细的项目归类学习、规则冲突解释和批量修正。
- 可配置数据源适配器与公司内部平台插件。
- Windows 自动更新、差分升级和签名发布。

## 三期规划

- 周报、月报 PPT 生成和可选择模板。
- macOS 桌面版、钥匙串凭据和对应采集能力。
- 团队可选模板市场，但保持无中心系统也能独立使用。
- 更完整的本地模型、模型效果评测和成本统计。
- 可选的匿名使用统计和用户反馈后台，默认关闭且不上传正文。

## 明确不做

- 不记录具体键盘输入和鼠标内容。
- 不后台静默上传截图或工作正文。
- 不自动把摸鱼内容包装成工作成果。
- 不在用户未确认时自动调用收费模型。
- 不把公司内部网址、账号、选择器和工作数据提交到公开仓库。
- 不把尚未实现的 Jira、企业微信、PPT 或 macOS 功能标记为可用。
